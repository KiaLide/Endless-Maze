# Endless Maze 素材與設定

遊戲程式碼已移除，這個 repo 目前只保留 **人物設定**、**人物圖**、**武器設定**、**防具設定**、**飾品設定** 與武器圖示。
（舊版遊戲程式碼可在 git 歷史或 tag `v1.0.5` 找回。）

## 人物 `characters/`

- `characters.json`：10 個職業（男女各 5）的設定：性別、職業名、角色名、介紹、基礎能力值（初稿）、被動技能、武器種類、圖片路徑
- `images/original/`：原始立繪（Canva 生成的縮圖，149×199）
- `images/pixel/`：轉成像素風的立繪（高 100px，透明背景）

| 性別 | 職業（角色名） | 武器 |
| --- | --- | --- |
| 男 | 劍士（雷恩）、騎士（格雷）、盜賊（凱）、法師（馬林）、狂戰士（布魯） | 長劍、長槍、匕首、法杖、戰斧 |
| 女 | 聖女（露西）、劍姬（艾莉亞）、魔女（莉莉絲）、遊俠（菲娜）、武鬥家（美玲） | 聖杖、細劍、魔杖、弓、拳套 |

## 武器 `weapons/`

- `weapons.json`：200 把武器（10 職業 × 20 階）的名稱、階級、材質、稀有度、數值、圖示路徑
- `icons/<職業>/01.png ~ 20.png`：32×32 像素圖示（`_x8` 為放大 8 倍版），`icons/<職業>_strip.png` 為 20 階橫排
- `sheets/<職業>.png`：每個職業的 20 階武器圖鑑
- `weapons.py`：產生以上所有檔案的程式（`python3 weapons/weapons.py`，需要 `numpy scipy pillow`；加 `--json-only` 只更新 `weapons.json`）

20 階材質：木 → 青銅 → 鐵 → 鋼 → 精鋼 → 白銀 → 王國 → 黑鐵 → 秘銀 → 烈焰 → 霜寒 → 雷鳴 → 翠玉 → 黃金 → 暗影 → 聖光 → 龍 → 星辰 → 混沌 → 神

稀有度：普通（1–4）、優良（5–8）、稀有（9–12）、史詩（13–16）、傳說（17–19）、神話（20）

## 能力值

6 項能力：生命 `hp`、攻擊 `atk`、防禦 `def`、速度 `spd`、爆擊率 `crit`（%）、閃避 `eva`（%）。
沒有等級與經驗值，能力只靠裝備（武器＋防具＋飾品）提升。

- 裝備不限職業；用其他職業的武器時，技能倍率與附加效果 ×0.75，普通攻擊不受影響
- JSON 裡的數值都是**基準值**：實際掉落時主數值（武器的攻擊、防具該套側重的能力）在基準值的 85%～115% 之間隨機，副屬性固定

- 武器：攻擊 = 5 × 1.18^(階−1) × 職業倍率（法師 1.15、狂戰士 1.2、魔女 1.1、聖女 0.9、其他 1.0），另有一項依武器種類的副屬性
- 防具：見下方

- `armor.py`：產生 `armor.json` 的程式（`python3 armor/armor.py`）

## 飾品 `accessories/`

- `accessories.json`：50 件飾品（10 職業 × 5 流派）的流派、名稱、能力值、主數值、詞條
- `accessories.py`：產生 `accessories.json` 的程式（`python3 accessories/accessories.py`）

飾品沒有等級，能力值約等於優良裝備；只有 1 個飾品欄。任何職業都能裝備，詞條對本職完整生效，其他職業裝備時針對技能的部分無效、其餘部分 ×0.75。

## 道具與金幣 `items/`

- `items.json`：29 種道具（回復藥水 3、暫時 buff 18、永久之種 6、女神之種 1、不死鳥之羽 1）、道具掉落表、金幣收入與價格
- 收入與價格都乘樓層係數 F = 1 + 0.1 ×（樓層 − 1）
